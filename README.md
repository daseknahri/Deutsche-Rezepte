# Deutsche Rezepte — „Authentische deutsche Rezepte zum Nachkochen“

German recipe site for the Facebook page **Deutsche Rezepte** (https://www.facebook.com/profile.php?id=61595540835887),
served at **deutsche-rezepte.getemoji.site**. WordPress on Docker (Coolify), fully set up on first start — no wp-admin clicks needed.
Cloned from the Oma Gerda (germ) repo and rebranded: same self-seeding engine, recipe pillars instead of story moods.

## What's inside
- `wp-content/themes/viral-reader` — parent theme (vendored, v1.9.37)
- `wp-content/themes/deutsche-rezepte` — brand child theme (v1.0.0, brick red #9C2B2E / warm cream):
  self-hosted Literata/Inter (no Google Fonts CDN, GDPR), category-coloured recipe pillars,
  end-of-recipe share + "next recipe" flow, sticky next-recipe bar, dark mode
- `wp-content/plugins/automation-hamri` — publishing/SEO/ads engine (vendored, build-v9 9.48.0)
- `data/bundles/*.zip` — recipe bundles (posts.json + images), imported on first start; empty until the first batch lands
- `seed/seed.php` — brand, German pages, menu, ads, recipe import (idempotent, resumable)
- `docker/site-init.sh` — waits for DB, syncs theme/plugin, installs WP (de_DE) once, runs the seed

## Recipe pillars (seeded categories)
Deutsche Klassiker · Schnelle Küche · Suppen und Eintöpfe · Backen und Kuchen · Vegetarisch

## Coolify
Docker Compose build pack, domain on the `wordpress` service. Env vars:
- `SERVICE_FQDN_WORDPRESS_80` (the domain), `SERVICE_USER_MYSQL`, `SERVICE_PASSWORD_MYSQL`,
  `SERVICE_PASSWORD_MYSQLROOT`, `SERVICE_PASSWORD_WPADMIN` — generated by Coolify
- `ADSENSE_CLIENT=ca-pub-…` — enables AdSense Auto ads (default ca-pub-6869205417923902)
- `HISTATS_ID` — Histats counter id for this site; unset/off = no counter (create a new Histats site first)
- `WP_ADMIN_EMAIL` — admin e-mail

Admin login: user `redaktion`, password = Coolify's `SERVICE_PASSWORD_WPADMIN`.
